# Cynbit Project Scope

I created this feature using the MERN stack. The idea is to help clients get an idea of how much time and budget their project might need before starting development.

They can select their project type and the features they want, and the app gives them an estimated number of development days and a budget range.

This can help clients plan their projects better and decide when they want to start or make changes to their plans.

### Tech Stack
- React.js
- Node.js
- Express.js
- MongoDB
- Bootstrap
